# CareLoop Clinics — No-Show Guard

Student project analyzing missed outpatient appointments using Python, SQL, ML and GenAI.

## Quick start
1. Open `01_ingest_clean.ipynb` in Google Colab (upload this repository or clone it).
2. Run cells top-to-bottom. Outputs `rejected_rows.json`, `appointments_clean.csv`, and `clinics_enriched.csv`. The weather API step needs internet.
3. In MySQL create schema with `load_data.sql`, import `appointments_clean.csv` using Workbench's import wizard, then run `02_queries.sql`.
4. Run `03_model.ipynb` for baseline/model comparisons and `test_risk_scores.csv`.
5. Run `04_genai.ipynb`; paste a free Gemini API key at runtime only. Do not store the key in files or commit it.

## Files
- `data/appointments.csv`, `data/clinics.csv`, `data/followup_notes.csv`: originals; do not edit.
- `01_ingest_clean.ipynb`: CSV module, pandas cleaning, NumPy summaries, weather enrichment, export.
- `rejected_rows.json`: rejected date/status records from the offline cleaning pipeline.
- `appointments_clean.csv`: cleaned data with `lead_days` and `no_show`.
- `clinics_enriched.csv`: clinic master with `temp_c` column (blank until weather API step is run).
- `load_data.sql`: MySQL schema setup.
- `02_queries.sql`: clinic rate, lead-time bands, monthly trend, within-city ranking.
- `03_model.ipynb`: logistic regression, trees, random forest, metrics, CV and threshold demonstration.
- `test_risk_scores.csv`: generated by running Part 3.
- `04_genai.ipynb`: Gemini structured note classification, Pydantic validation, error tests and cross-tab.
- `notes_analysed.csv`: first 10 notes offline-rule-based starter rows; replace with Gemini output by running Part 4.

## Limitations
This is a learning exercise on synthetic/observational data. No-show risk scores are not causal, and small clinic-level samples are noisy. Model threshold should be chosen with the clinic's follow-up capacity and validated on future data. Offline note classifications are placeholders until the Gemini notebook is run.

## Business questions
- Which clinics show higher missed-appointment rates?
- Does longer booking lead time correlate with missed appointments?
- How do no-show rates vary month to month?
- What reasons appear in follow-up notes, and what low-cost interventions could help?

## API key safety
Never commit your Gemini API key. Enter it at runtime or use Colab Secrets. Remove notebook cell output containing credentials before committing.
